## 5. 残余风险（如实记录，不承诺消除）

1. 复核完成到 `os.replace` 之间的极短窗口仍存在；
2. 锁只约束遵守协议的丞相实例，编辑器 / Git 不遵守；
3. 同 UID 进程可绕过应用层检查（架构限制）；
4. 冲突后需重新读取、重新生成、重新审批；
5. `os.replace` 之后缺少目录 `fsync`（R-03，掉电时替换可能未持久化，但不损坏）。
